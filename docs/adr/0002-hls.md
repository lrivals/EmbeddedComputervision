# ADR 0002 — Accélérateur en Vitis HLS (C++)

- Statut : **accepté** (2026-10-04)

## Contexte

Le golden model C++ (§10.5 étape 3) reproduit déjà le nid de boucles tuilé du §10.2.

## Décision

L'accélérateur est écrit en C++ Vitis HLS. Les noyaux partagent les en-têtes de
`cpp/golden/include/golden/` quand c'est possible, et le testbench HLS compare au golden.

## Conséquences

- Un seul langage de la référence au matériel ; C-sim rapide.
- Il faut écrire le golden sans allocation dynamique ni bibliothèque standard non
  synthétisable dans les parties partagées.
- Une version RTL de la PE reste possible plus tard (M9).

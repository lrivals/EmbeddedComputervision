# ADR 0002 — Accelerator in Vitis HLS (C++)

- Status: **accepted** (2026-10-04)

## Context

The C++ golden model (§10.5 step 3) already reproduces the tiled loop nest of §10.2.

## Decision

The accelerator is written in Vitis HLS C++. The kernels share the headers of
`cpp/golden/include/golden/` when possible, and the HLS testbench compares against the
golden model.

## Consequences

- A single language from the reference to the hardware; fast C-sim.
- The golden model must be written without dynamic allocation or non-synthesizable
  standard library in the shared parts.
- An RTL version of the PE remains possible later (M9).

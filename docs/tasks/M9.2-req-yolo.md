# M9.2 — Quantification REQ-YOLO (ADMM, puissances de 2)

Objectif : reproduire la quantification de 2019-ding sur Tiny-YOLOv2 : poids 6 bits
« mixed powers-of-two », dont la multiplication se réduit à deux décalages et une addition
[2019-ding#008.1], obtenus par ADMM [2019-ding#009.1].

### [x] T9.2.1 — Projecteurs sur les niveaux autorisés
- **Spec** : §9.2 (REQ-YOLO) · **Dépend de** : T4.2 · **Taille** : S
- **Livrables** : `python/yolo/quant/pow2.py` + tests
- **Acceptation** : la projection rend le niveau le plus proche (équidistant et puissances
  de 2) ; produit par deux décalages et une addition == produit entier
- **Notes** : α par canal de sortie : la structure survit à la fusion BN (α'_f = s_f·α_f)
- **Fait** : `pow2.py` (`mixed6`, `uniform6`, `pot5`, `int8` ; α par canal sur 32 échelles ;
  codes (signe, a, k)) ; `test_pow2.py`.

### [x] T9.2.2 — PTQ puissances de 2
- **Spec** : §9.2 · **Dépend de** : T9.2.1, T4.5 · **Taille** : S
- **Acceptation** : mAP VOC2007 test des poids Darknet projetés sans réentraînement
  (plancher de T9.2.3)
- **Fait** : `tools/quant_lowbit.py --weights pow2` (activations INT8 calibrées) : mixed6
  **52,46**, uniform6 54,35 (INT8 : 55,66).

### [ ] T9.2.3 — ADMM
- **Spec** : §9.2 · **Dépend de** : T9.2.1, T9.3.3 · **Taille** : L
- **Livrables** : `python/yolo/train/admm.py`, `tools/train.py --admm`
- **Acceptation** : ‖W − Z‖ → 0 au fil des itérations ; mAP après projection finale
- **Profils PC** : grille ρ / pas Z-U et diagnostic de non-convergence : [T12.6](M12-profils-pc.md#-t126--admm-req-yolo)
- **Notes** : pas W = SGD sur la perte + ρ/2‖W − Z + U‖² ; pas Z = projection de W + U ;
  U ← U + W − Z ; schéma (équidistant ou puissances de 2) choisi par couche
- **Fait** : `admm.py` (hook du `Trainer`, ρ croissant, `admm.csv`), validé sur un problème
  quadratique. Run de 600 itérations (ρ 1e-3 → 0,023) : **non convergé** (résidu 0,06 → 0,08)
  et mAP 43,07, pire que la PTQ (l'affinage sans BN a dégradé le réseau, hypothèse non
  vérifiée) — `results/req_yolo.md`.
- **Reste** : ρ plus grand, plus d'itérations, plan par couche ; mAP flottante de
  l'affinage seul.
- **GPU** : optionnel (`--device gpu`, à ajouter), voir [T12.11](M12-profils-pc.md#-t1211--entraînement-sur-cpu-ou-gpu-au-choix)

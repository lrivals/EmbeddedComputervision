# M9.3 — 4-bit quantization

Goal: weights and activations on 4 bits with a learned clipping constrained to a power of 2
[2024-yan#006.0] and an 8-bit first layer split into two 4-bit convolutions
[2024-yan#007.3]. This milestone also lays the infrastructure shared with M9.2
(parameterised bit width, fake-quant, QAT mode).

### [x] T9.3.1 — Parameterised bit width in the integer contract
- **Spec**: §9.3 · **Depends on**: T4.3, T5.2, T6.2 · **Size**: M
- **Deliverables**: per-layer `qmax` in `python/yolo/quant/`, the manifest, the golden
  model and the HLS kernel
- **Acceptance**: INT8 unchanged (tests, `golden-check`, `csim-gcc` green); an exported
  model with `qmax = 7` passes the golden model and the C-sim to the byte
- **Notes**: the container stays int8 in memory (no 2 × 4-bit packing here)
- **Done**: `qmax` per conv (`int_layers.clip_q`, `QConv.qmax/wqmax`, optional `qmax`
  field of the manifest and of the schema, `golden::clip_q`, `LayerDesc.qmax`: 27 words,
  `check_regmap`). INT8 unchanged (tests, golden-check, C-sim, sw-sim); w4a4 PTQ and QAT
  models: golden == Python to the byte, `tb_net` 0 differences.

### [x] T9.3.2 — Fake-quant and straight-through estimator
- **Spec**: §9.2 (PTQ or QAT) · **Depends on**: T1.3 · **Size**: M
- **Deliverables**: `python/yolo/quant/fake_quant.py` + tests (deliverable planned by
  T4.6)
- **Acceptance**: gradcheck green (STE: derivative 1 inside the range, 0 outside);
  clipping c = 2^k with k learned (rounding in the forward pass, STE on log₂ c)
- **Done**: `fake_quant.py` (per-channel weights, output in hardware order: rounding,
  integer leaky, clipping; LSQ for the step), `QATNetwork`; `test_fake_quant.py`:
  gradcheck of the surrogate function (with and without leaky).

### [x] T9.3.3 — QAT mode of the trainer
- **Spec**: §7.1, §9.2 · **Depends on**: T9.3.2, T2.7 · **Size**: M
- **Deliverables**: `tools/train.py --qat`, fine-tuned weights in `build/train/`
- **Acceptance**: the loss decreases in 4-bit QAT from the Darknet weights; exact
  checkpoint resume
- **Notes**: network with folded BN (convs with a bias); lr 1e-4 [2026-fata#015.3]; CPU
  only, ≈ 0.45 s/image
- **Done**: `tools/train.py --qat w4a4 --qat-steps …`, `lowbit.py`,
  `tools/quant_lowbit.py` (PTQ, export, dumps). 600 iterations (batches of 8): loss 16.0 →
  10.1.
- **GPU**: optional (`--device gpu`, to add), see [T12.11](M12-profils-pc.md#--t1211--training-on-cpu-or-gpu-by-choice)

### [x] T9.3.4 — Split first layer
- **Spec**: §9.3 · **Depends on**: T9.3.1 · **Size**: S
- **Acceptance**: x = 16·x_hi + x_lo, conv(x) = 16·conv(x_hi) + conv(x_lo) equal to the
  integer (Python and golden model)
- **Done**: `int_layers.split4` / `conv_acc_split4` (real dump input), `golden::mul_split4`
  (all 65,536 int8 pairs).

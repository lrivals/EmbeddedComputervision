# M9.3 — Quantification 4 bits

Objectif : poids et activations sur 4 bits avec un écrêtage appris contraint à une
puissance de 2 [2024-yan#006.0] et une première couche 8 bits décomposée en deux
convolutions 4 bits [2024-yan#007.3]. Ce jalon pose aussi l'infrastructure commune à M9.2
(largeur de bits paramétrée, fake-quant, mode QAT).

### [ ] T9.3.1 — Largeur de bits paramétrée dans le contrat entier
- **Spec** : §9.3 · **Dépend de** : T4.3, T5.2, T6.2 · **Taille** : M
- **Livrables** : `qmax` par couche dans `python/yolo/quant/`, le manifeste, le golden et le
  noyau HLS
- **Acceptation** : INT8 inchangé (tests, `golden-check`, `csim-gcc` verts) ; un modèle à
  `qmax = 7` exporté passe le golden et la C-sim à l'octet
- **Notes** : le conteneur reste int8 en mémoire (pas de paquetage 2 × 4 bits ici)

### [ ] T9.3.2 — Fake-quant et estimateur straight-through
- **Spec** : §9.2 (PTQ ou QAT) · **Dépend de** : T1.3 · **Taille** : M
- **Livrables** : `python/yolo/quant/fake_quant.py` + tests (livrable prévu par T4.6)
- **Acceptation** : gradcheck vert (STE : dérivée 1 dans la plage, 0 hors plage) ; écrêtage
  c = 2^k avec k appris (arrondi en avant, STE sur log₂ c)

### [ ] T9.3.3 — Mode QAT du trainer
- **Spec** : §7.1, §9.2 · **Dépend de** : T9.3.2, T2.7 · **Taille** : M
- **Livrables** : `tools/train.py --qat`, poids affinés dans `build/train/`
- **Acceptation** : la perte décroît en QAT 4 bits depuis les poids Darknet ; reprise de
  checkpoint exacte
- **Notes** : réseau à BN fusionnée (convs avec biais) ; lr 1e-4 [2026-fata#015.3] ; CPU
  seulement, ≈ 0,45 s/image

### [ ] T9.3.4 — Première couche décomposée
- **Spec** : §9.3 · **Dépend de** : T9.3.1 · **Taille** : S
- **Acceptation** : x = 16·x_hi + x_lo, conv(x) = 16·conv(x_hi) + conv(x_lo) égal à
  l'entier près (Python et golden)

### [ ] T9.3.5 — mAP et coûts
- **Spec** : §10.4 · **Dépend de** : T9.3.3, T9.3.4 · **Taille** : S
- **Livrables** : `results/quant_4bits.md`
- **Acceptation** : mAP VOC2007 test en PTQ 4 bits et en QAT 4 bits, face à INT8 (55,66) ;
  gains estimés (2 MAC par DSP, mémoire des poids ÷ 2)
- **Profils PC** : PTQ wXaY [T12.4](M12-profils-pc.md#-t124--ptq-basse-précision-m92-m93), QAT [T12.5](M12-profils-pc.md#-t125--qat-4-bits)

# M13 — Figures (optional)

Goal: explain the project in pictures. The figures already exist in `results/*.md`,
[benchmarks.csv](../../results/benchmarks.csv), `build/` and `tools/perf_model.py`; before
M13, only the rooflines of `tools/roofline.py` (`results/roofline_*.png`) were plotted. M13
adds figures along five axes:

- the **architecture** of the models and of the accelerator (sections B, C);
- the **results** of the tests and measurements (D);
- the **development** of the project (E);
- the **from-scratch reimplementation**: each essential building block reprogrammed in pure
  NumPy, without PyTorch, OpenCV, scikit-learn or devkit, explained by its mathematical
  functions (F);
- the **architecture of the networks in detail**, layer by layer and tensor by tensor (G);
- the **packed PE and YOLOv4-tiny** of M23 and M24 (H).

Each figure can be **regenerated by one command** and reads its data from a versioned file
or one produced by an existing tool. No figure is copied by hand.

**State**: 61 tasks done out of 61. `make figures` produces 61 figures in about two minutes,
gathered in the gallery [results/figures.md](../../results/figures.md). The code is
complete; some data remains to be produced:
- the Vitis syntheses, which make the bars of T13.24 solid, and the board stage of the
  result figures: [deferred/M13](deferred/M13-figures.md);
- `make test-durations` (tier N), for the durations panel of T13.30.

## Shared conventions

### Tooling

- **Package**: `tools/figures/`. It contains one module per family (`modeles.py`,
  `materiel.py`, `resultats.py`, `projet.py`, `maths.py`, `reseaux.py`) and a shared
  `style.py`.
- **Commands**: `python -m tools.figures <name|family|all>`, and `make figures`, which
  regenerates everything whose data is present. A figure whose source is missing is
  skipped with a message; it is not an error.
- **matplotlib import**: as in `tools/roofline.py`, `matplotlib.use("Agg")` and a lazy
  import in the plotting function. The `yolo` package stays pure NumPy
  ([ADR 0001](../adr/0001-numpy-pur.md)): matplotlib is never imported from
  `python/yolo/`.
- **Dependencies**: extra `plots = ["matplotlib>=3.7"]` in `python/pyproject.toml`.
  Diagrams are drawn with Graphviz (`dot`), or in mermaid when they stay in a `.md`.
- **Style** (`style.py`):
  - a categorical palette safe for colour-blind readers;
  - a fixed colour per stage: float, integer, C-sim, board;
  - a fixed colour per network: v2, v3;
  - one-column width (6.4 in) or full page (10 in);
  - saved as 150 dpi PNG only.

### Outputs

- **Files**: `results/figures/<family>/<name>.png` (PNG only).
- **Index**: `results/figures.md`, a gallery with, for each figure, the image, an
  explanatory sentence, the command and the data source.
- **Cross-references**: each relevant results `.md` also points to its figure (for example
  `map_stades.md` → T13.13).

### Rules

- **Projection or measurement**: a figure that has not been measured on the board is marked
  on the plot ("C-sim projection", "estimate", "to measure"), with a distinct marker or
  line. A figure never mixes projection and measurement without a legend.
- **Subsets**: the rules of [M12](M12-profils-pc.md#rules) apply. A figure published in
  `results/` shows mAPs on the 4,952 images. A figure on `--subset` stays in
  `build/figures/`.
- **Cost**: the R/M/N tiers of M12 apply. `make figures` only runs R generators. Those that
  need an evaluation (M or N) read the outputs already present in `build/`.
- **Shared acceptance** (all tasks):
  - the figure is produced by `make figures`;
  - it is referenced in `results/figures.md`;
  - its values are equal to those of the source (a test rereads the source);
  - it stays readable in greyscale.
- **Mathematical datasheet** (sections F and G): each plate carries, besides the figure:
  - the exact **equations**, in matplotlib mathtext, copied from the module docstring (a
    single source: the docstring);
  - the **path** `module:function` of the plotted code;
  - the **library avoided** (for example `torch.nn.Conv2d`, `cv2.resize`,
    `torchvision.ops.nms`, `sklearn.cluster.KMeans`);
  - the **test** that checks the implementation (`python/tests/test_*.py`).

  The curves are computed **by calling the repository code** (never a rewrite in the
  generator), on toy inputs with a fixed seed: the figure proves what the code does.

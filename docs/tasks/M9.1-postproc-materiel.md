# M9.1 — Hardware post-processing

Goal: decoding and NMS in the FPGA, in integers only, as 2024-zhang does
[2024-zhang#013.1, #014.0, #014.2]; the ARM only receives the kept boxes.

### [x] T9.1.1 — All-integer post-processing (Python and C++ reference)
- **Spec**: §8.1, §8.2, §9.4, §10.3 · **Depends on**: T4.4, T5.3 · **Size**: M
- **Deliverables**: `python/yolo/infer/hw_postproc.py`,
  `cpp/golden/include/golden/hw_postproc.hpp` + tests
- **Acceptance**: no float between the int8 head and the boxes (corners in Q4 pixels, Q16
  scores, IoU by cross products); Python == C++ to the byte on the dumps and on random
  heads; mAP gap to the sorted reference NMS measured on VOC2007 test
- **Notes**:
  - NMS without sorting (2024-zhang): a candidate that overlaps a selected box with a
    better score is rejected; otherwise it replaces the selected boxes it overlaps. This is
    not always the result of the sorted greedy NMS (a box removed by a box that is itself
    replaced does not come back): a gap to measure, not to cancel
  - IoU > θ with θ = p/q ⟺ (p+q)·inter > p·(a₁+a₂): no division
  - grid stride (416/S) a power of 2: the cell → pixels step is a shift
- **Done**: `hw_postproc.py` (Q4 corners, Q8 anchors, Q16 scores with a reciprocal
  ⌊2³²/Σe⌋ per cell, 256 slots, overflows counted) and `hw_postproc.hpp` (allocation-free
  primitives reused by the kernel); `golden_run hwpp`. Python == C++ to the byte on the
  v2/v3 dumps (thresholds 0.25 and 0.005) and on random heads (`test_hw_postproc.py`); gap
  to the float boxes < 1 Q4 pixel. `int-hwpp` variant of `eval_quant.py`: mAP **55.56**
  against 55.66 (−0.10, entirely due to the unsorted NMS and to the integer coordinates;
  50 overflows over 4,952 images, with no effect).

### [x] T9.1.2 — HLS kernel `yolo_post`
- **Spec**: §10.3 · **Depends on**: T9.1.1, T6.1 · **Size**: M
- **Deliverables**: `hls/kernels/postproc.cpp`, `hls/tb/tb_post.cpp`
- **Acceptance**: boxes == golden `hw_postproc` (C-sim g++) on the dumps and on random
  heads; cycles estimated for the 845 candidates of Tiny-YOLOv2, set against 0.38 ms
  [2024-zhang#020.3]
- **Notes**: fixed selection capacity (overflow reported, never silent)
- **Done**: `yolo_post` (head descriptors and tables in a `tab` array, result
  [n, overflows, boxes]); `tb_post` (ctest): 1,014 cases == golden. Cycles: ≈ 1,400 for one
  image at threshold 0.25 (7 µs at 200 MHz, against 0.38 ms for 2024-zhang), 342,000 in
  the worst case where all 845 cells pass (NMS with 256 slots, 1 comparison per cycle) —
  `results/postproc_hw.md`.
- **Remaining**: synthesis (`make hls-synth-post`).

# Notebooks (M14)

Index generated by `python -m tools.notebooks all` (`make notebooks`) from the registry of `tools/notebooks/matrice.py`; do not edit by hand. The notebooks are versioned empty, or executed in full without error (outputs visible here); their results go to `build/notebooks/<dataset>/<model>/`. See [docs/tasks/M14-notebooks.md](../docs/tasks/M14-notebooks.md).

Tier (M12 rules): first pass (`SUBSET = 50`) / full pass (`SUBSET = 0`, or `ITERS = 4000` for training); statistics (M16): annotations / pixels.

Display only: [figures_live.ipynb](figures_live.ipynb) shows the figures (M13, runs) and sorts them by family, with their context.

Analysis: [analyse_balayages.ipynb](analyse_balayages.ipynb) compares the batch × subset sweeps of every dataset (reads the executed `_sweep` notebooks, no GPU or data).

Dataset analysis: [analyse_jeux.ipynb](analyse_jeux.ipynb) compares the dataset statistics of all datasets (reads the executed `_stats` notebooks, no data or GPU).

Decision explanation: [explain.ipynb](explain.ipynb) runs `tools/explain.py` (maps, integer attribution, miss causes, M36).
